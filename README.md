## Setup instructions

In the project directory, run:

### `npm install`

Installs all the needed dependencies from npm. Recommended local version > 6.
This project uses `pretty` alongside `eslint` to properly prettify the code while developing. 
If using VSCode add the following to the workspace's `settings.json`:

```
  editor.codeActionsOnSave": {
    "source.fixAll.eslint": true 
  },
```

### `npm run start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

The page will reload if you make edits.\
You will also see any lint errors in the console.
